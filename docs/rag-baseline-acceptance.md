# RAG 检索基线验收记录（本地真实模型与合成题集已就绪）

此文件是可执行的验收模板。本地已接入真正的 BGE Embedding/ReRank，并用完全虚构的 16 题、16 段文档跑通独立检索烟测：在 12 道有答案题上，Embedding Recall@5=1.0、ReRank Recall@1=0.75、Recall@3/5=1.0、NDCG@5=1.0；热启动 P50≈120 ms、P95≈374 ms（单台 M2 Pro、MPS，小样本）。这只证明模型协议、维度及小样例检索可用，**不代表真实企业题集、WeKnora 端到端 RAG、答案忠实度或真实 AD 已通过**。完整验收仍须绑定提交、镜像 digest、已批准数据集指纹和模型版本；外发数据范围及费用须先经管理员批准。

## 准备

1. 可先用仓库自带的 `synthetic-zh-v1` 合成题集：`dataset/benchmarks/synthetic-zh-v1/` 下已有 5 个 Parquet 文件，生成方法与模型启动见 `scripts/local-rag-models/README.md`。若要使用企业题集，必须先取得数据责任人批准，在 `EVALUATION_DATASET_DIR/<dataset_id>/` 放置已脱敏文件并只读挂载给 app；不要将企业原文、AD 凭据或题集提交到 Git。
2. 本地模型为 `BAAI/bge-small-zh-v1.5`（512 维）和 `BAAI/bge-reranker-base`。确认正式部署所选版本、输入长度及服务地址；评估界面会拒绝名称含 `mock`/`test` 或维度不大于 3 的 Embedding。启动前以一条中文样本验证 Embedding、ReRank 返回有效结果。已有 3 维知识库必须新建或重建索引，不可直接复用。
3. 按“中文术语 / 跨文档组合 / 无答案 / 权限允许 / 权限拒绝”给题集分层。每题记录期望的证据段落 ID、参考答案或应拒答标记。权限题另列测试身份及其直接/嵌套 AD 组；现有离线评估 API **不执行** 身份切换，权限题须在真实登录会话下独立验证。
4. 记录外部模型发送范围：语料、问题、检索片段、提示词分别是否获准。未获准的数据只能用本地模型；不要用外部 LLM Judge 检查这些内容。

在「设置 → RAG Evaluation」选择数据集 ID、正式 Embedding、正式 ReRank 和对话模型。每次只改变一个变量，比较相同 `dataset_sha256` 的成功任务。任务详情与历史保存在数据库 `evaluation_runs`；重启后应能重新读取。记录如下表，原始运行 ID 保留供复核。

当前 API 持久化检索/生成聚合指标、P50/P95、token 数和逐题生成答案/证据 ID，界面可展开逐题复核，但**不自动计算货币费用、引用准确率、证据忠实度或拒答正确率**。这些栏位在人工/受控评审完成前保持“待填”，不可用 BLEU/ROUGE 代替。忠实度可按“答案每个可核验断言均由给定证据支持；无支持断言记失败”标注；引用准确性需逐条确认引用指向相应证据。可参考 [RAGAS](https://arxiv.org/abs/2309.15217) 的 faithfulness/context relevance 和 [ARES](https://arxiv.org/abs/2311.09476) 的少量人工标注校准评审方法，但不能直接声称运行了这些框架。

## 权限与时效单独验收

- 对同一问题分别用本地管理员、AD 直接组成员、嵌套组成员、非成员、禁用用户验证列表、搜索/RAG、下载与预签名、智能体和分享入口；非成员不得返回受限片段或生成其摘要。
- 在 Nextcloud 修改、删除、撤权后比较 `received`、`dispatched`、`applied` 水位；`202` 仅表示收到提示，只有文档解析/发布、删除和撤权已在检索入口生效时才可判为闭环完成。
- 执行 `docs/LDAP_AD.md` 中真实 AD 验收清单，特别是多域控故障切换、禁用/移组撤权、失联过期与恢复；本地隔离 LDAP 测试不替代企业域控结果。

任何一项未完成时，报告中标注“未验收”，不要以模型 API 调用成功或同步任务 success 代替检索、权限和答案质量的验收。
