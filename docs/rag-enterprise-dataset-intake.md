# 企业脱敏 RAG 题集交接清单

这是交接模板，**不是数据使用批准**。仓库只包含完全虚构的合成题集；不要把企业原文、真实姓名、账号、域组、凭据或真实题集提交到 Git、PR、聊天记录或公开 CI。

## 需要数据负责人提供

1. 一份可留档的批准记录：数据负责人、批准日期、使用目的、有效期、允许参与测试的人员/环境、删除期限，以及允许发送给哪些 Embedding、ReRank、对话和评审模型。逐项注明“本机处理”还是“可外发”；空白视为不允许外发。
2. 经复核的脱敏语料和问题，覆盖中文术语、跨文档组合、无答案、直接/嵌套 AD 组允许访问、非成员拒绝访问。每题标注期望证据段落 ID、参考答案或应拒答标记；权限题另列测试身份与预期可见资源。使用稳定的虚构标识，不在题集中存真实 AD 密码或令牌。
3. 每个文件的 SHA-256、脱敏方法及抽样复核记录。若保留金额、日期、政策条款，说明它们已被批准用于该测试；不能仅因删掉姓名就称为“脱敏完成”。

## WeKnora 评估文件格式

在仓库外的受控目录中建立一个只读的 `<dataset_id>/`，ID 只用字母、数字、下划线和连字符，最长 64 字符。提供以下五个 Parquet 文件：

| 文件 | 字段 | 含义 |
| --- | --- | --- |
| `corpus.parquet` | `id: int64`, `text: string` | 脱敏证据段落；可含不被问题引用的干扰段落 |
| `queries.parquet` | `id: int64`, `text: string` | 脱敏问题 |
| `answers.parquet` | `id: int64`, `text: string` | 有参考答案的题目的答案 |
| `qrels.parquet` | `qid: int64`, `pid: int64` | 问题到所有必要证据段落的关系；无证据题不写行 |
| `qas.parquet` | `qid: int64`, `aid: int64` | 问题到参考答案的关系；无答案/应拒答题不写行 |

应用会拒绝重复的题目、段落、答案 ID，重复的证据/答案关系，以及指向不存在对象或空白答案的关系。正式运行前还要抽查每道题的证据是否真的足以支持参考答案；结构校验不能证明标签正确。

`qrels.parquet` 和 `qas.parquet` 不存 AD 身份。离线评估不会切换登录用户，也不会验证空间、组、分享、API Key 或智能体权限。请在受控目录另留权限测试矩阵（题目 ID、匿名化测试身份、直接/嵌套组、预期允许/拒绝、资源 ID），用真实登录会话逐入口执行，不要把离线预过滤结果当成授权通过。

## 执行与签收

1. 将受控题集只读挂载到应用的 `EVALUATION_DATASET_DIR`，不要覆盖仓库的 `synthetic-*` 目录。批准前不运行真实题集，也不把文档发送给外部模型。
2. 记录 Git 提交、镜像 digest、题集 ID/文件 SHA-256、模型名和权重版本、并发、运行 ID、空间及权限测试身份。比较版本时只比较相同题集指纹和指标口径的运行。
3. 对召回、引用准确性、答案逐断言忠实度、无答案拒答、权限泄漏、P50/P95、token 与费用分别复核；生成答案使用真实且已获准的对话模型，确定性测试桩不能用于质量签收。
4. 对 Nextcloud 修改、删除、撤权分别核对事件水位和检索可见性；`202` 只证明收到提示。按有效期清理受控题集和临时测试账号，并由数据负责人/系统管理员签收结果。
